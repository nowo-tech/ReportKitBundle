# Report Kit Bundle demo (Symfony 8.1, FrankenPHP worker, MySQL)

```bash
make up      # http://localhost:8223 (127.0.0.1 only)
make setup   # composer install + database
make down
```

S0 scaffold: the home page shows the bundle registered and disabled, its container parameters and the MySQL
connection. The features of the next slices are added here as they land (docs/ROADMAP.md).
